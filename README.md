## Host scope

The MP4 files stay outside the Git tree.
The release tag identifies this set of four originals.
Keep the asset names and tag unchanged to preserve the download links.
The source website repository stays separate.

Each file is below the 2 GiB limit for GitHub Release assets.
GitHub permits up to 1,000 assets per release.
See [GitHub release limits](https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases).

## Restore

Remove the website download links before you remove a release asset.
Retain the local original files and their SHA256 records.
Keep the Squarespace HLS playback links.
Publish replacements under a new release tag to preserve this version.
Get owner approval before you delete the release or repository.
